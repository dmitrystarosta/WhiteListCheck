## Зачем нужен этот документ

Это первая контрольная точка молодого сайта BelyjSpisok.ru. В отличие от
старых проектов, здесь нет многолетнего поискового наследия: сайт и
приложение появились летом 2026 года, поэтому данные позволяют
наблюдать, как поисковые системы с нуля формируют понимание тематики
проекта.

Документ нужен для повторного сравнения через 1--2 месяца и далее. При
новом анализе следует использовать те же типы выгрузок из Яндекс
Вебмастера и Яндекс Метрики.

## Исходное позиционирование

BelyjSpisok.ru --- сайт Android-приложения «Белый список?».

Основная задача приложения --- определить состояние интернет-доступа и
помочь понять, действует ли режим доступа только к разрешённым ресурсам
(«белый список»).

Важно: приложение **не является VPN и не предназначено для обхода
ограничений**. Это принципиально учитывать при SEO-анализе, поскольку
значительная часть поискового спроса вокруг темы белых списков связана
именно с обходом.

# Нецелевой кластер «обход / VPN»

В первой же поисковой семантике появился крупный кластер запросов:

-   как обойти белые списки на андроиде;
-   скачать обход белых списков на телефон;
-   обход белых списков на мобильном интернете;
-   обход белых списков бесплатно на Android;
-   VPN для белых списков;
-   тоннель для обхода белых списков;
-   близкие варианты.

Некоторые из таких запросов уже получают позиции в ТОП-10.

Это **не означает, что сайт следует оптимизировать под обход**. Скорее
всего, поисковик видит сильную тематическую близость, а пользователи
часто формулируют проблему белых списков именно через поиск способов
обхода.

### Правило для дальнейшей работы

Не добавлять на сайт искусственно тексты и страницы про «обход белых
списков», VPN или тоннели только ради большого поискового спроса.

Не менять позиционирование приложения ради нецелевого трафика.

При повторном анализе отдельно считать:

1.  целевой кластер «проверка / определить / приложение / тест /
    виджет»;
2.  нецелевой кластер «обход / VPN / тоннель».

Желательный сценарий --- рост абсолютного объёма и доли первого
кластера.

# Особый показатель: расширение семантики

Для молодого сайта количество новых релевантных запросов может быть
важнее абсолютного трафика.

При следующем анализе отдельно определить:

1.  какие запросы сохранились;
2.  какие исчезли;
3.  какие новые целевые запросы появились;
4.  какие запросы улучшили позиции;
5.  какие запросы впервые вошли в ТОП-10;
6.  расширяется ли понимание функциональности приложения.

Особенно интересно, начнёт ли поисковик самостоятельно связывать сайт с
такими понятиями, как:

-   определение режима сети;
-   проверка ограничений мобильного интернета;
-   автоматическая проверка;
-   уведомление об изменении режима;
-   Android TV;
-   виджет-индикатор.

Не следует искусственно набивать сайт этими формулировками только ради
эксперимента. Нужно наблюдать, насколько существующий нормальный
пользовательский контент позволяет поисковику прийти к ним
самостоятельно.

# Что считать хорошим результатом

Через 1--2 месяца положительными сигналами будут:

-   устойчивый рост показов относительно первых 20--50 показов в день;
-   сохранение или улучшение позиций при расширении числа запросов;
-   рост числа целевых запросов;
-   увеличение поисковых визитов;
-   рост запросов с явным намерением найти инструмент проверки;
-   появление новых long-tail запросов про реальные функции приложения;
-   сохранение ясного позиционирования «проверка», а не «обход»;
-   увеличение переходов к секции скачивания и/или в магазины
    приложений;
-   появление устойчивого органического трафика из Google наряду с
    Яндексом.

------------------------------------------------------------------------

# Что не считать автоматически проблемой

На молодом сайте не следует переоценивать:

-   колебания показов по отдельным дням;
-   изменение позиции на несколько пунктов;
-   CTR запроса с 2--5 показами;
-   временный рост нецелевых запросов;
-   небольшие изменения поведенческих метрик;
-   единичные длинные или короткие визиты.

Первый месяц --- период активного тестирования сайта поисковыми
системами.

------------------------------------------------------------------------

# Правило на период наблюдения

На текущем этапе **не проводить крупные SEO-переделки только ради
поисковых запросов из первой статистики**.

Особенно:

-   не превращать сайт в ресурс про обход ограничений;
-   не создавать страницы под VPN/обход;
-   не набивать тексты поисковыми ключами;
-   не менять ясное описание назначения приложения ради более частотных,
    но нецелевых запросов.

Главная задача --- сохранить точное и честное позиционирование продукта
и дать поисковым системам накопить данные.
